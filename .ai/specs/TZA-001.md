# TZA-001: Restructure into a Kotlin Multiplatform project with an immutable address domain model

## Summary
Rename `:library` to `:core`, convert it to a Kotlin Multiplatform library (Android, JVM, iOS arm64 + simulator arm64), delete the hard-coded stub sources and mutable models, and add the immutable model (`Region`, `District`, `Ward`, `Mtaa`, `Kitongoji`, `DatasetInfo`), the browse-only `AddressRepository` interface, deterministic ID generation (`AddressIds`) and a test fake. `:app` keeps building against `:core` and becomes a placeholder until TZA-003. Key trade-off: iOS targets are declared but likely cannot be compile-verified on this machine (no full Xcode).

## Module Impact
`:library` → `:core` (renamed, KMP), `:app` (dependency + `MainActivity` cleanup). No other modules exist yet.

## Architecture Conformance
No project architecture rules exist. Applying the ticket's own design: pure Kotlin in `commonMain` (no `android.*`/`java.*`); one top-level declaration per file; model types carry no logic and are immutable (`val`, `List`); `AddressRepository` is an interface in `:core` with implementation deferred to TZA-003; `AddressIds` is the single ID source shared later by importer and data store.

**New top-level naming decision:** module `:core`, package root `com.omarshehe.tzaddress` (later modules: `:data`, `:ui`, `:importer`). No prior name exists, so this is recorded in a new `.ai/context.md` module map as its own step (**scope expansion outside the ticket's Files table, needs approval**).

Boy-scout: nothing in the old `library/` is kept, so nothing to conform.

## Implementation Steps
1. `git mv library core` for files that survive (`.gitignore`, `consumer-rules.pro`, `proguard-rules.pro`); `git rm` the old sources, `arrays.xml`, tests, manifest, `library/build.gradle.kts`.
2. `gradle/libs.versions.toml`: add `kotlin = "2.4.20"`, `compileSdk`/`minSdk`/`targetSdk` versions, `kotlin-test` library, plugins `kotlin-multiplatform` and `android-kotlin-multiplatform-library` (AGP-versioned).
3. `build.gradle.kts` (root): alias the two new plugins `apply false`; keep the app plugin; remove `android.library`.
4. `settings.gradle.kts`: `include(":core")` instead of `:library`.
5. `core/build.gradle.kts`: `kotlin { androidLibrary { namespace = "com.omarshehe.tzaddress"; compileSdk/minSdk from catalog; withHostTest {} }; jvm(); iosArm64(); iosSimulatorArm64(); sourceSets { commonTest.dependencies { implementation(libs.kotlin.test) } } }`, JVM target 17, `explicitApi()`.
6. Write model files (one type per file) with the fields from the ticket (`Region(code, name)`, `District(code, name, regionCode)`, `Ward(postcode, name, districtCode)`, `Mtaa(id, name, wardPostcode)`, `Kitongoji(id, name, mtaaId)`, `DatasetInfo(version, sourceEdition, generatedAt)`).
7. `AddressRepository.kt`: the browse interface exactly as in the ticket.
8. `AddressIds.kt`: `object AddressIds { fun slug(name: String): String; fun mtaaIds(wardPostcode: String, names: List<String>): List<String>; fun kitongojiIds(mtaaId: String, names: List<String>): List<String> }`. Slug: lower-case, drop `'`, `"`, `’`, replace runs of non-`[a-z0-9]` with `-`, trim `-`, empty → `unnamed`. ID = `<parentId>/<slug>`; duplicates under one parent get `-2`, `-3` in encounter order.
9. Tests (written first, see Test Plan).
10. `gradle.properties`: `org.gradle.configuration-cache=true`; fix anything it flags.
11. `app/build.gradle.kts`: `project(":core")`. `MainActivity.kt`: remove the `Regions`/`Districts` imports and calls.
12. `.ai/context.md`: create with module map (`:core`, `:app`), package root, target list, build/test commands, and the iOS-verification caveat.
13. Build/verify: `:core:jvmTest`, `:core:testAndroidHostTest`, `:core:compileKotlinIosArm64` (best effort), `:app:assembleDebug`, `:app:assembleRelease`, then `./gradlew build` with configuration cache; grep checks for `android.`/`java.` in `commonMain` and for `com.omarshehe.library`.

## Test Plan (TDD)
- `AddressIds.slug` → `"Kivukoni"→"kivukoni"`, `"Jang'ombe"→"jangombe"`, `Mtambani "A"→"mtambani-a"`, `"Kariakoo Magharibi"→"kariakoo-magharibi"`, `"  A   B "→"a-b"`, `"---"`/`""`→`"unnamed"`.
- `AddressIds.mtaaIds("11101", ["Kivukoni","Sea View"])` → `["11101/kivukoni","11101/sea-view"]`.
- Duplicates: `["Rubumba","Rubumba","Rubumba"]` → `[".../rubumba",".../rubumba-2",".../rubumba-3"]`; a later literal `"Rubumba-2"` name must not collide (its slug also `rubumba-2`) → test asserts uniqueness across the whole list (collision gets the next free suffix).
- `kitongojiIds` builds on the mtaa ID: `"11101/kivukoni/<slug>"`.
- Determinism: same input twice → identical output.
- `AddressRepositoryContractTest` against `FakeAddressRepository`: `regions()` returns loaded regions; `districts("unknown")` → empty; browse chain region→kitongoji resolves parents; `info()` returns the fake's `DatasetInfo`.
- Not unit-tested: Gradle/plugin wiring, iOS compile (build-only), `MainActivity` (build-only).

## Risks & Gotchas
- **No full Xcode** (`xcode-select -p` → CommandLineTools): iOS Kotlin/Native compilation likely fails locally. Plan: declare the targets, attempt `compileKotlinIosArm64`, and report the real result; if it can't run, the iOS AC is unverified here and I'll say so rather than claim it.
- **`iosX64` dropped** from the target list (Intel simulator only; the ticket named "x64"). The ticket text will get a Scope note.
- **Immutability AC** cannot be meaningfully unit-tested in common code without reflection; I interpret it as: model files contain no `var`, checked by a documented grep, plus contract test compiling against `List` types. Ticket AC gets a Scope note.
- **AGP 9 KMP plugin** (`com.android.kotlin.multiplatform.library`): host-test source set and task name (`testAndroidHostTest`) need `withHostTest {}`; the plugin's Android manifest handling differs from `com.android.library`. Exact IDs/versions verified by the first build.
- **Configuration cache** may flag AGP/KMP or old task usage; fixes limited to build files.
- **Public API break:** the old `com.omarshehe.library` package was never published; no shim.
- **.idea files** remain uncommitted and are not staged with this ticket.
